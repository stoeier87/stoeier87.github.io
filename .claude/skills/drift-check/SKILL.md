# /drift-check

Standalone, or as `/loop /drift-check`.

This exists because of a specific failure. `AGENTS.md` was generated by Copilot in PR #13 — created and merged twelve seconds apart — and within three weeks it was wrong on five points: it forbade Tailwind after Tailwind was adopted, cited a `styles.css` that had been deleted, described a `push`-to-`main` deploy trigger that no longer existed, claimed the Firebase config wasn't committed when it was, and omitted four pages. Nobody noticed, because nothing checked.

**A contract that is confidently wrong is worse than no contract**, because agents act on it. This is the watchdog.

## What to check, claim by claim

Walk `CLAUDE.md` and treat every factual assertion as a testable claim. Verify against the source, not against memory.

**Deploy claims** — the highest-stakes ones, since everything hangs off them.

- Does `deploy.yml` still have no `push` trigger? Read the file.
- Do `preview.yml`'s trigger globs still match what `envs.json` says?
- Does `stage.yml` still deploy to `destination_dir: stage`?
- Do all publishing workflows still share `concurrency: gh-pages-write` with `cancel-in-progress: false` and `keep_files: true`?
- Is the `FIREBASE_*` validation list still seven keys, and is `FIREBASE_MEASUREMENT_ID` still generated-but-unvalidated?

**File and line references.** Every `file:line` citation in `CLAUDE.md`, `DECISIONS.md`, `ANALYSIS.md` and `standards.json`. Do the files exist, and does the cited line still contain what the doc says it does? Line numbers rot fastest — `script.js:52-125`, `arcade/arcade.js:83`, `index.css:104`, `scoreboard/index.html:43-87`.

**Config coherence.**

- `envs.json` → `pages.routes` versus the actual `**/*.html` files, and versus `expectedHtmlCount`.
- `tokens.ts` `THEME_MIRROR` versus the `@theme` block — `npm run tokens` does this; run it.
- `standards.json` rules that reference paths or line numbers.
- Does the head order claim (`tailwind.css` last) hold in **every** page? Grep them all.

**Stated invariants.**

- Is `base: "./"` still set in `vite.config.js`?
- Is `dependencies` still empty in `package.json`?
- Are the duplication counts in ADR-008 still right — `drawPlanet` ×3, back-pill ×4, starfield ×5? Recount, don't trust.
- Are the six known issues still true? A fixed one that's still listed as broken is drift in the other direction, and just as misleading.

**Live state.** Is `CNAME` still present on `origin/gh-pages`? Is the orphaned-preview count still what the docs say?

## Report

Only report what has actually drifted. A clean run should say so in one line.

```
drift-check — 3 findings

CLAUDE.md:214  known issue 2 says "eight stale previews are up now"
               → recount: 5. Number is stale.
               evidence: git ls-tree -d origin/gh-pages preview/

ANALYSIS.md:88 cites script.js:197 for drawPlanet
               → drawPlanet is now at script.js:203 (file grew by 6 lines above it)

standards.json rule-of-three.knownClusters
               → back-pill is now ×5; space-bar/space-bar.css picked up a second
                 definition in <commit>. ADR-008 count is out of date.
```

For each: the claim, what's actually true, and the command or file that proves it.

## Rules

- **Read-only by default.** Report drift; do not edit `CLAUDE.md` unless the user says to. The docs are the human's statement of intent, and silently rewriting them destroys the signal.
- **When the code and the doc disagree, don't assume the doc is wrong.** Sometimes the code drifted and the doc is the correct intent — the width-gated parallax was a case of exactly that. Present both and let the human decide which one moves.
- As a loop: long intervals (1800s+ or on-demand). Docs drift on the timescale of merges, not minutes. Hold quietly (`noop: true`) when clean, and don't re-report an unchanged finding every tick.
